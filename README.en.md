# Professional Title Engine · Master Edition

> Extract the content kernel first, then adapt it to distribution. A headline may be punchy, but it may not fabricate.

`professional-title-engine` is a bilingual headline Skill for creators, editorial teams, newsletters, and Chinese self-media platforms.

## Core capabilities

- Headline generation, diagnosis, rewriting, and candidate comparison
- Multi-platform headline matrices
- Six content kernels: unexpected fact, reversal, real cost, conflict, decision-changing number, reader stake
- Six-class zero-fabrication promise ledger: numbers, entities, identities, results, path/scope, degree words
- Safe / Punchy / Max intensity levels
- Historical headline performance review
- Account-specific Title DNA learning
- Reverse engineering of strong external headlines by mechanism, not sentence cloning
- CASE / TENTATIVE / STABLE evidence confidence

## Quick usage

```text
Use $professional-title-engine to create 9 headlines for this article.
Extract the kernel first, then give Safe / Punchy / Max versions.
```

Learn an account's Title DNA:

```text
Here are my last 50 headlines and 24-hour performance data.
First determine what is comparable, then learn my Title DNA. Do not turn correlation into causation.
```

Reverse-engineer strong examples:

```text
Analyze why these headlines work. Learn the mechanisms, not the wording.
Then apply those mechanisms to my own article.
```

## Installation

### Codex

Copy the entire directory:

```text
skills/professional-title-engine/
```

Do not copy only `SKILL.md`; the Skill also uses `references/` and `templates/`.

### Claude Code

The repository includes `.claude-plugin/plugin.json` and can be loaded as a Claude Code plugin repository.

## Language routing

The primary `SKILL.md` matches the user's language automatically:

- Chinese input → Chinese output
- English input → English output
- bilingual only when explicitly requested

Localized full files:

- `SKILL.zh-CN.md`
- `SKILL.en.md`

## Core model

**Headline = content kernel × truthful promise × reader state × distribution context × expression intensity × personal Title DNA**

The Skill never guarantees traffic, CTR, or platform distribution. Historical data is used to identify account-level correlations and preferences; causal claims require stronger evidence.
