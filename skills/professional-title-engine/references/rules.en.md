# Headline Master Reference Rules (English)

## Priority
Truth > content kernel > reader stake > specificity > platform fit > personal Title DNA > click appeal.

## Historical data
Prefer comparisons within the same account, content surface, similar content type, and similar observation window. Reads, views, CTR, completion, likes, saves, shares, and follows remain separate metrics. Without experiments or A/B tests, never phrase correlation as causation.

## Title DNA
- CASE: one observation; record it, do not make it a rule.
- TENTATIVE: multiple comparable examples point the same way, but counterexamples/confounders remain.
- STABLE: repeated comparable pattern with counterexample checks; still not a universal platform law.

## External examples
Learn mechanisms only: content kernel, information order, curiosity gap, action verbs, punctuation, rhythm, reader stake, and fact/attitude separation. Do not copy fixed syntax, catchphrases, creator authority, or persona.

## Persistence
Write to a case library or DNA file only when the user explicitly asks to save, record, or update it.
